# 自定义因子复用

## 接口和数据

所有环境通过统一 request 调用真实接口，无运行时 Mock 或本地因子库：

- GET `/footprint3/customFactor/list`：四项筛选 name/factor/institution/year，以
  及 pageNum/pageSize。
- GET `/footprint3/customFactor/{id}`：用户单选并点击确定后读取最新详情，成功才
  回填。
- DELETE `/footprint3/customFactor/{id}`：确认删除后调用，成功刷新选择及管理列表
  。

列表直接使用 id/name/factor/unit/institution/year 和 rows/total。id 与 factor 保
持字符串，年份未知为空。前端名称和来源筛选仍最多 40 字，数值筛选不限制小数位数
；不截断输入或接口返回的数值。默认每页 10 条。

只有回填旧表单时按第一个斜杠拆分 unit。选择复用因子替换当前因子快照，再执行原手
填提交回调和单位换算；其他字段、其他运输行及原排放源提交保持不变。库 id 不传入
factorObj.id、matchId 或 customFactorId。后端负责收录、去重和归属，前端没有额外
入库操作或轮询。

请求错误交由统一请求层提示。详情业务失败清空选择并刷新列表；网络失败允许重试。失
败、关闭、切换用户/企业或表单权限失效时不回填。删除不改变已经填写在排放源中的快
照。

## 碳云入口

CustomFactorReuseContext 默认关闭，仅在以下业务开启，且必须满足字段原有编辑权限
：

- 快速核算列表、画布、检查模型结果打开的普通排放源表单。
- 排放源库和自定义模型库的排放源新增、编辑、复制。
- 过程核算列表、画布和过程库详情中的输入排放源新增、编辑、复制及可编辑详情表单。
- 上述表单的可编辑运输因子；供应链填报复用上述核算入口，保持原标识和权限。

排除：

- 所有分享页面（可编辑、只读及旧分享）的排放源及运输因子均排除复用；可编辑时保留原手填操作。

- 单元过程新增/编辑/复制，产品和产出物中的回用因子。这三类表单注册
  FormilyFactorWithoutReuse，即使外层开启也保持原操作。
- 过程库首页新增/复制整个过程。
- 主排放源为发起收数模式时的运输因子。字段接线监听主表单 matchWay；切换后立即撤
  销复用入口。
- 旧 Excel 任务恢复表单、无因子入口的在线排放明细表格、废弃或注释页面。
- 只读分享、快照、认证详情、系统模型和模板预览，不增加操作或请求。

PROCESS_CUSTOM_FACTOR_REUSE_ENABLED 只控制过程场景的排放源，不扩大到单元过程和产
品。

## Agent

同一套接口与公共组件，仅在普通会话、可写项目会话右侧的快速核算模型开启。保留
Agent 的保存和模型刷新流程，不将碳云页面整体覆盖到 Agent。会话分享、项目概览、认
证审核快照、移动端等只读入口不接入。

## 验证

- `node --test scripts/test-custom-factor-reuse.cjs`：真实请求协议、详情确认、字
  符串精度、原提交回调、字段隔离、权限、过期响应、删除和入口排除。
- `node --test scripts/test-product-account-emission-fields.cjs`：现有排放源字段
  回归。

测试中的请求替身仅用于自动化验证，不进入应用运行时；测试通过不代表全部真实页面已
经联调。
