## 折叠侧栏与后台路由修复

根因：折叠菜单从 inline 的 flex 布局切到 block 布局后，自定义 SVG 容器沿文本基线定位，图标向下偏移；后台每个菜单路径各自创建了一个 lazy 组件和顶层 Route，切换时整个布局及 WorkspaceProvider 被重新挂载。

修复：团队后台统一为 `/system/carbonAgent/team` 父布局路由，显式允许子路径；内容区域使用精确匹配的 Route/Switch，默认路径跳转工作台，未知子路径展示 404。侧栏、顶部和空间上下文保持挂载，各业务页仍按路由独立挂载，避免成员/席位表单状态混用。菜单链接和图标/键盘导航均走 React Router，语言前缀由 Router basename 处理，不重复拼接。

折叠侧栏保持 72px，菜单宽 56px，与 Ant Menu collapsedWidth 一致；图标放入居中的 16px 容器，选中菜单组显示背景，底部返回按钮使用图标和可访问名称。折叠浮层继续使用原有分组结构。

浏览器使用真实测试组织验证：成员→席位→后退→前进保持折叠状态，菜单实例与顶部空间 Select ID 保持不变；折叠工作台图标、配额/日志/企业设置浮层可正常导航；1280×800 和 1440×900 无横向溢出，6 个图标垂直中心偏差均为 0px。`/zh/system/carbonAgent/team` 正确跳转工作台，团队后台菜单链接保留单个 `/zh` 前缀，企业信息与工作台切换正常；`/team/members/unknown` 展示 404，返回工作台正常。本轮未修改成员、席位、额度或订单数据。

验证：修改的 TSX/路由配置 ESLint 0 error；团队入口定向 lint 无警告；团队 Node 测试 16/16；全量 lint 98 个既有错误，TypeScript 709 条既有诊断，无新增签名；`git diff --check` 通过。未运行 build。
