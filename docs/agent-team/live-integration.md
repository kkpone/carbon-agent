## 本轮修复

1. 个人空间开通入口与团队管理员权限分开判定。
2. 无 AI 资格时所有首页 Composer 与建议问题禁用；建议问题按场景/标题去重，消除真实重复数据导致的 React key 警告。
3. 财务商品订单状态采用真实数字编码 0～4 的独立映射，不能复用团队权益订单状态。
4. 财务、执行、消耗和审计时间统一北京时间格式；缺失值显示“—”。
5. 后端失败审计使用 REQUEST_ + Controller 方法名，补齐中文业务映射。
6. 删除前端 schema-preflight.sql、虚拟数据预览入口和虚拟截图。保留纯逻辑单元测试；screenshots 现在只包含真实联调截图。
